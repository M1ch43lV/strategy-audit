# Archived predecessor audit

This directory preserves publication pages, one-off side analyses, generated
signals, session logs, and five selected case studies from the pre-regime audit.
They are historical evidence, not current market-regime benchmark results.

- `ANALYSIS*` and `results/`: selected case studies;
- `DCA*` / `dca.py`: entry-averaging investigation;
- `DEPTH*` / `depth.py`: drawdown-depth investigation;
- `RESOLVABLE*` / `resolvable.py`: barrier-race sample-size investigation;
- `TRAILING_SENSITIVITY*`: trailing-stop sensitivity investigation;
- `signals_*.csv`: predecessor signal exports;
- `logfile_*.log`: old interactive run logs.

For current work start at the repository-root `README.md`, `HANDOFF.md`, and
`strategy_status.html`.
